Daslight 5

Sur Mac, active un bus dans Configuration audio et MIDI → Studio MIDI → Pilote IAC. Sélectionne ce bus ici, puis active son entrée et « MIDI Clock » dans Daslight. Choisis « MIDI Clock Sync » comme source BPM. Entre deux machines, utilise une session MIDI réseau.

grandMA2

Envoie une note par beat vers une entrée MIDI de la régie. Dans Setup → Remote Input Setup → MIDI Remotes, ajoute le canal et la note choisis, type CMD, commande Learn SpecialMaster 3.1. Active les MIDI Remotes. Cette sortie règle le Speed Master 1 par tap tempo.

OSC & réseau

Les messages sont /djlink/bpm (float), /djlink/beat (1–4), /djlink/deck et /djlink/playing (entiers). Ils nécessitent un mapping dans le logiciel destinataire. Ouvre l’adresse du Mac sur le port 8080 pour voir le mix depuis une tablette sur le même réseau.

Les retards mesurent les interruptions du flux. Les trous de séquence ne sont affichés que si le compteur du lecteur progresse de façon exploitable ; ils ne prouvent pas à eux seuls une perte sur le câble. Les beats absents sont une estimation croisant le tempo annoncé et les sauts de phase, hors boucles non confirmées ou non multiples de quatre beats.

Les fichiers de log restent sur le PC qui exécute l’application. Aucun téléchargement de log n’est proposé sur le réseau.
